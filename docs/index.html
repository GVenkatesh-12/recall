recall_

A modern, lightweight note capture & clipboard utility for your terminal. Local-first, SQLite-backed, and installable anywhere with one command.

$ one-line install — works on Linux, macOS & Windows (Git Bash)
$ curl -fsSL https://GVenkatesh-12.github.io/recall/install.sh | bash

Features

  • Local storage — notes live in a single-user SQLite database at ~/.recall/recall.db. Nothing leaves your machine.
  • Clipboard integration — copy any saved note straight to your system clipboard.
  • Stateless mapping — refer to notes by their simple displayed index (1, 2, …) when copying or deleting.
  • Beautiful UX — color hierarchy, unicode decorators, and clean table layout.
  • Cross-platform — prebuilt binaries for Linux, macOS, and Windows (x86_64 & arm64).

Install

The installer downloads the latest release binary, verifies its SHA-256 checksum, and places it on your PATH — no build tools required.

# Linux / macOS / Windows (Git Bash)

curl -fsSL https://GVenkatesh-12.github.io/recall/install.sh | bash

Prefer downloading the binary yourself? Grab a recall-<target>.tar.gz/.zip plus its .sha256 from the latest release:

PlatformAsset
Linux · x86_64recall-x86_64-unknown-linux-gnu.tar.gz
Linux · arm64recall-aarch64-unknown-linux-gnu.tar.gz
macOS · Intelrecall-x86_64-apple-darwin.tar.gz
macOS · Apple Siliconrecall-aarch64-apple-darwin.tar.gz
Windows · x86_64recall-x86_64-pc-windows-msvc.zip

Or build from source:

git clone https://github.com/GVenkatesh-12/recall.git

cd recall && cargo install --path .

💡 On Linux, ensure X11 or Wayland is available for clipboard support. Everything else (including SQLite) is bundled — no extra system packages needed.

Quick start

All commands below work immediately after installing — recall creates ~/.recall/recall.db automatically on first run.

recall # list all notes (most recent first)

recall -s "Buy milk" # save a note

recall 2 # copy note #2 to the clipboard

recall -d 2 # delete note #2 (with confirmation)

recall -d 2 --force # delete without confirmation
